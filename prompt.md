# Prompt: Professional developer portfolio

Menga dasturchi uchun jiddiy, professional portfolio sayt yarat. Faqat HTML, CSS va vanilla JavaScript (framework yo'q).

**Egasi:** Erkinjon Nabijonov, frontend dasturchi. Profil rasmi: `images/profile.jpg`.

**Fayl tuzilmasi:** `index.html`, `css/style.css`, `js/main.js`, `images/` (profile.jpg, project1-3.svg). Rasmlarni keyin o'zim almashtiraman.

**Bo'limlar:** sticky navbar, Hero (rol, katta ism, qisqa tavsif, 2 tugma: Bog'lanish va CV yuklab olish, vertikal profil rasmi va "yangi loyihalarga ochiq" holati), Men haqimda, Ko'nikmalar (Frontend / Backend / Vositalar guruhlari), Tajriba (vaqt chizig'i), Loyihalar (qatorli ro'yxat: rasm, nom, tavsif, texnologiyalar, yil), Aloqa (email va ijtimoiy tarmoqlar), footer.

**Funksiyalar:**
1. Dark/Light rejim: tugma bilan almashadi, localStorage'da saqlanadi, birinchi marta tizim rejimiga qaraydi. Ranglar CSS o'zgaruvchilarida.
2. UZ/EN tili: barcha matn `data-i18n` kalitlari orqali JS lug'atidan olinadi, tugma bilan darhol almashadi, tanlov saqlanadi.
3. Faqat hero'da bitta sokin kirish animatsiyasi, hover'da nozik o'zgarishlar. `prefers-reduced-motion` hurmat qilinadi.
4. To'liq responsive, klaviatura fokusi ko'rinadigan.

**Dizayn:** vazmin va toza. Har bir bo'lim chap tomonda kichik sarlavha ustuni, o'ngda mazmun ko'rinishida (muharrirlik tartibi), ingichka chiziqlar bilan ajratilgan. Bitta aksent rang: dark rejimda ko'k (#62b0ff) chuqur ko'k-kulrang (#0f1722) fonda, light rejimda to'q ko'k (#1456d9) och kulrang (#f6f7f9) fonda. Shrift: IBM Plex Sans va IBM Plex Mono. Dekorativ effektlar, gradientlar va bir xil kartalar yo'q.

**Natija:** barcha fayllarni to'liq kod bilan ber, ishlashga tayyor holda.
